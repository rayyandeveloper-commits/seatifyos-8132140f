## Stack
- TanStack Start (SSR React) + TanStack Router (file-based) + TanStack Query
- Supabase (auth + DB) — credentials in .replit userenv as VITE_SUPABASE_URL + VITE_SUPABASE_PUBLISHABLE_KEY
- Tailwind CSS v4, Framer Motion, Radix UI/shadcn components, Recharts
- Vite via `@lovable.dev/vite-tanstack-config` (kept, works fine on port 5000)

## Auth
- Supabase email/password only. No Google OAuth.
- Session in localStorage via Supabase JS client.
- Shell.tsx handles auth guard (redirects to "/" if no session).

## Key files
- `src/lib/queries.ts` — all data hooks + types (Cabin, Student, Payment, Attendance, etc.)
- `src/lib/reminders.functions.ts` — server fn for Twilio WhatsApp
- `src/routes/api/public/hooks/send-reminders.ts` — daily cron endpoint
- `src/integrations/supabase/client.ts` — Supabase client
- `src/styles.css` — full design system (glass, gradients, oklch dark theme)
- `src/components/layout/Shell.tsx` — auth guard + command palette (⌘K)
- `src/components/layout/Sidebar.tsx` — nav with unread badge
- `src/components/layout/CommandPalette.tsx` — ⌘K search palette
- `src/routeTree.gen.ts` — manually maintained + auto-overwritten by router plugin on dev restart

## DB tables (existing)
- cabins, students, notifications, app_settings, cabin_history, reminder_logs

## DB tables (V2 — requires migration in Supabase SQL Editor)
- payments — fee tracking (monthly_fee | admission | security_deposit | misc)
- attendance_logs — daily check-in/out per student
- Migration file: `supabase/migrations/v2_upgrade.sql`
- ALSO adds optional columns to students: father_name, address, aadhaar, alternate_phone, emergency_contact

## WhatsApp / Twilio
- Direct Twilio API (not Lovable gateway)
- Requires TWILIO_ACCOUNT_SID + TWILIO_AUTH_TOKEN in Replit Secrets
- Sender number stored in app_settings.twilio_from

## Payments hooks pattern
- usePayments / useSavePayment / useDeletePayment — all with `retry: 0`
- `isError` from usePayments signals table doesn't exist yet → show MigrationBanner
- Dashboard and Analytics defensively use `payError` flag to show 0 instead of crashing

## Routes (10 total)
/ → /dashboard, /cabins, /students, /renewals, /payments (V2), /attendance (V2),
/analytics, /imports, /notifications, /settings, /api/public/hooks/send-reminders

## routeTree.gen.ts
- Auto-generated by TanStack Router vite plugin on dev restart
- Safe to manually edit; plugin will overwrite on next restart
- Must keep payments + attendance entries if plugin doesn't detect them
